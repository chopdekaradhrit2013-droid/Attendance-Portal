# Attendance Portal

A V1 web app for professors to mark attendance, manage classes, and track students who fall below 75%.

## Stack
Vite + React + TypeScript. Data is stored in the browser (`localStorage`) so the app works immediately after deploy — no backend keys required.

## Run locally
```bash
npm install
npm run dev
```

## Use
1. Open the landing page
2. Sign up with professor details
3. Create a class
4. Add students (or import CSV: `Roll No,Name,Email`)
5. Mark attendance
6. Review history, analytics, and export reports
